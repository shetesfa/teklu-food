# ተክሉ ጌታቸው የከብት እርባታ እና የወተት ተዋጽኦ ማቀነባበሪያ ድርጅት
## Teklu Getachew Cattle Breeding & Dairy Processing Enterprise
### የንግድ ሥራ አመራር ሥርዓት (Business Management System — Mobile-First & Offline-First PWA)

---

## 🌟 አጠቃላይ እይታ (System Overview)

ይህ የንግድ ሥራ አመራር ሥርዓት የተገነባው በአዲስ አበባ ዙሪያ (ቢሾፍቱ/ሞጆ አካባቢ) ለሚገኘው የ **ተክሉ ጌታቸው የከብት እርባታ እና የወተት ተዋጽኦ ማቀነባበሪያ ድርጅት** ነው። ሥርዓቱ የከብት እርባታውን፣ የወተት ማቀነባበሪያውን፣ የሬስቶራንትና ምግብ ሽያጩን፣ የውጭ ግዢዎችን፣ ወጪዎችንና የፋይናንስ እንቅስቃሴዎችን በአንድ የተቀናጀ ማዕከል ያስተዳድራል።

### ዋና ዋና ጠንካራ ጎኖች፦
- 📱 **ሞባይል-ተኮር (Mobile-First UI/UX)**፦ 100% ለስማርት ስልኮች የተመቻቸ፣ የታችኛው ዳሰሳ (Bottom Nav)፣ ትላልቅ የንክኪ ቁልፎች።
- 📶 **ከመስመር ውጭ የሚሰራ (Offline-First PWA)**፦ ደካማ ወይም የተቆራረጠ ኢንተርኔት ባለበት አካባቢ ያለ ምንም እንከን ይሰራል፤ Service Worker እና IndexedDB ይጠቀማል።
- 🔄 **ራስ-ሰር ማመሳሰል (Automatic Sync Engine)**፦ ከመስመር ውጭ የተከናወኑ ሽያጮች፣ ግዢዎች፣ ወጪዎችና ዝውውሮች ኢንተርኔት ሲገኝ በአይደምፖተንሲ ቁልፎች (Idempotency Keys) ተደጋጋሚነት ሳይፈጠር ወደ ሰርቨሩ ይመሳሰላሉ።
- 🇪🇹 **ሁለት ቋንቋዎች (Bilingual)**፦ አማርኛ (ነባሪ) እና እንግሊዝኛ (Amharic & English) በቅጽበት ይቀያየራል።
- ⚖️ **የተስተካከለ የሂሳብ አያያዝ (Proper Accounting Logic)**፦
  - **ጠቅላላ ትርፍ (Gross Profit)** = የሽያጭ ገቢ - የተሸጡ ዕቃዎች ወጪ (COGS)
  - **የተጣራ ትርፍ (Net Profit)** = ጠቅላላ ትርፍ - የስራ ማስኬጃ ወጪዎች
  - **የውስጥ ዝውውር መርህ**፦ ከእርሻ ወደ ሬስቶራንት የሚደረጉ ዝውውሮች ለተጠቃለለው ድርጅት ውጫዊ ገቢ ወይም ወጪ ተደርገው አይቆጠሩም!
  - **የባለቤት መውጣት መርህ**፦ የባለቤት የግል መውጣት የስራ ማስኬጃ ወጪ ሳይሆን የካሽ/ባንክ ሚዛንን ብቻ ይቀንሳል።
  - **የምግብ አዘገጃጀት (Recipes)**፦ ሬስቶራንት ውስጥ ምግብ (ለምሳሌ ጥብስ) ሲሸጥ ጥሬ ግብዓቶች (ስጋ፣ ሽንኩርት፣ ዘይት) በራስ-ሰር ይቀነሳሉ።

## 🚀 ዋና ዋና ሞጁሎች (Core Modules)

1. **ዳሽቦርድ (Dashboard)**: የዛሬ ሽያጭ፣ ግዢ፣ ወጪ፣ መውጣት፣ ጥሬ ገንዘብ፣ ባንክ (CBE)፣ ቴሌብር፣ የክምችት ዋጋ፣ አነስተኛ ክምችት፣ ያልተከፈሉ ዕዳዎች እና የትርፍ ግምት።
2. **የሬስቶራንት ሽያጭ ማዕከል (POS)**: ፈጣን ንክኪ ሽያጭ፣ የክፍያ ዘዴዎች (ጥሬ ገንዘብ፣ ቴሌብር፣ ንግድ ባንክ፣ ድብልቅ፣ ብድር)፣ ደረሰኝ ማመንጨት።
3. **ክምችት እና ምርቶች (Inventory & Stock)**: 3 የተከፋፈሉ መጋዘኖች (የእርሻ መጋዘን፣ የሬስቶራንት ክምችት፣ ዋና ማከማቻ)፣ የመክፈቻ ክምችት፣ የክምችት ማስተካከያ።
4. **ከእርሻ ወደ ሬስቶራንት ዝውውር (Internal Transfers)**: የመላክ፣ የመቀበልና ውድቅ የማድረግ ሂደት (የተጠቃለለ ድርጅታዊ ትርፍ ሳያዛባ)።
5. **የእርሻና ወተት ምርት (Farm Production)**: የወተት፣ ቅቤ፣ አይብ ምርት፣ የባች ቁጥር እና የማብቂያ ቀን መዝገብ።
6. **የውጭ ግዢዎች (Purchases)**: ከውጭ አቅራቢዎች የሚገዙ ዕቃዎች፣ የትራንስፖርት ወጪ፣ ከፊል/ሙሉ ክፍያ እና ዕዳ።
7. **የምግብ አዘገጃጀት (Recipes)**: የምግብ ንጥረ-ነገሮች አያያዝ እና በራስ-ሰር የሚከናወን የክምችት ቅነሳ።
8. **ወጪዎች እና መውጣቶች (Expenses & Withdrawals)**: የስራ ማስኬጃ ወጪዎች ከባለቤት መውጣት ተለይተው የሚመዘገቡበት።
9. **ደንበኞች እና አቅራቢዎች (Contacts & Debt Management)**: የብድር ሽያጭ፣ የአቅራቢ ዕዳ እና የዕዳ ማስታረቂያ።
10. **ዕለታዊ ሂሳብ መዝጊያ (Daily Closing)**: የሲስተም እና የእጅ ላይ ጥሬ ገንዘብ ማመሳከሪያ፣ ልዩነት ማብራሪያ እና መቆለፊያ።
11. **የፋይናንስ ሪፖርቶች (Reports & P&L)**: የትርፍና ኪሳራ መግለጫ፣ የምርቶች አትራፊነት፣ የገንዘብ ፍሰት (Cash Flow)።
12. **የመረጃ ምትኬ (Backup & Export)**: ሙሉ የድርጅቱን ዳታ በ JSON ፎርማት ወደ ኮምፒውተር/ስልክ ማውረጃ።

## 👥 የተጠቃሚ ሚናዎች (User Roles)

- **ዋና አስተዳዳሪ (Super Admin)**: ሙሉ ቁጥጥር፣ የተጠቃሚዎች ፈቃድ፣ የዕለት ሂሳብ ዳግም መክፈቻ፣ ዳታ ኤክስፖርት።
  - የተጠቃሚ ስም: `admin` | የይለፍ ቃል: `Admin@123`
- **ስራ አስኪያጅ (Manager)**: የቀን ተቀን ስራዎች፦ ሽያጭ፣ ግዢ፣ ወጪ፣ ዝውውር፣ ምርት።
  - የተጠቃሚ ስም: `manager` | የይለፍ ቃል: `Manager@123`

## 🛠️ የቴክኖሎጂ ቁልል (Tech Stack)

- **የፊት ለፊት (Frontend)**: Mobile-First PWA, Modern Vanilla JS Component Architecture, Service Worker (`sw.js`), IndexedDB (`db.js`), Modern Responsive CSS (`app.css`)
- **የኋላ ክፍል (Backend)**: PHP 8.2 RESTful API, PDO, HMAC-SHA256 Token Authentication, Audit Logging Engine
- **ዳታቤዝ (Database)**: MariaDB / MySQL 10.4+ (`utf8mb4_unicode_ci` ንጹህ የአማርኛ ድጋፍ)

## 💻 የአጠቃቀም እና የመጫኛ መመሪያ (Setup Guide)

### 1. የዳታቤዝ ዝግጅት
XAMPP MySQL ን ያስጀምሩ እና በ PHP ስክሪፕቱ ዳታቤዙን ይጫኑ፦
```bash
php database/import_seed.php
```

### 2. አፕሊኬሽኑን መክፈት
በማንኛውም አሳሽ (Chrome / Edge / Safari) የሚከተለውን አድራሻ ይክፈቱ፦
👉 **http://localhost/teklu-food/**

በስልክዎ ለመክፈት ኮምፒውተርዎ እና ስልክዎ በተመሳሳይ Wi-Fi ላይ ሆነው፦
👉 `http://<የኮምፒውተርዎ-IP>:80/teklu-food/`

በ Chrome ውስጥ **"Add to Home Screen"** በማለት እንደ አንድሮይድ አፕሊኬሽን በቀላሉ ይጫኑት!

### 3. አውቶሜትድ ፍተሻዎችን ማስኬድ
